A Lightning wallet you host yourself and own outright.

Allod runs next to your own Bitcoin and Lightning node and gives you a web wallet, a REST API and Nostr Wallet Connect. No sign-up, no company between you and your money. Open source under the MIT license.

Get started Read the source

Allodium, in medieval law: land held in absolute ownership, owing rent and service to no lord. That is the idea, applied to a Lightning node.

Everything runs on a machine you control.

One Docker Compose bundle starts the whole stack on a VPS, an Umbrel or a small computer at home. Allod is the top layer: the wallet, the accounts and the connections to your apps.

A local gossip server that verifies channels

Allod builds the Lightning graph itself. A sidecar collects channel announcements and checks every funding transaction against your own node's UTXO set before the Lightning node routes over it.

No third-party services

Each of these is replaced by something on your machine or left out. Payments route over channels with peers you choose, and Wallet Connect uses several relays so no single one matters.

Separate accounts, one ledger

Sub-wallets for family, projects or apps, each with its own balance, connections and addresses. A double-entry ledger records every sat, and a payment is settled only when the node confirms it.

Domains and gateways, managed for you

Bring a domain or buy one from Settings, and Allod manages its DNS records with DNSSEC. If your node has no public address, rent a gateway and pay for it over Lightning: HTTPS passes through a WireGuard tunnel without being decrypted on the way, and your home address never appears in DNS.

A gateway renews itself from your wallet before it expires, up to a maximum you set.

Names on your own domain

Lightning addresses, BIP-353 names and NIP-05, for the main wallet and for every account. Allod checks a name against DNS before it calls it live.

Where the others lead

Allod is in early development, and the projects above are mature and in daily use. Alby Hub supports several Lightning engines, has an app store and ships native mobile push today. LNbits has a large set of extensions. BTCPay Server has point of sale and store plugins. phoenixd manages channels for you. Allod runs on ldk-server only, has one owner per instance, and leaves keysend out by design.

Get started.

You need a Debian or Ubuntu machine with an 80 GB disk. The installer adds Docker only if it is missing.

  1. Run the installer

    It asks for the network, the chain source, a domain, Tor and backups, then writes the settings. As root it installs to /opt/allod, as any other user to ~/allod. It downloads signed images, builds nothing and starts nothing.

    curl -fsSL https://github.com/allod-me/allod/releases/latest/download/install.sh | sh

    To read and verify the script before you run it:

    curl -fsSLO https://github.com/allod-me/allod/releases/latest/download/install.sh
curl -fsSLO https://github.com/allod-me/allod/releases/latest/download/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS && less install.sh
sh install.sh

  2. Start the stack

    The installer prints these commands with your install directory filled in.

    cd ~/allod    # /opt/allod if you installed as root
docker compose pull
docker compose up -d

  3. Open the setup link

    This prints a one-time link. Without a domain the wallet listens on 127.0.0.1:8029 only, so reach it through an SSH tunnel or the Tor address. With a domain, use --base-url https://your.domain.

    docker compose exec allod allod setup-link --base-url http://127.0.0.1:8029

  4. Connect your signer and write down the phrase

    The wizard connects a Nostr signer, which becomes the owner key, then creates or restores the recovery phrase. The Lightning node starts once Bitcoin has synced. After that, open a channel and you can pay and receive.

Early development. Try Allod on signet or testnet4 first (ALLOD_NETWORK=signet) and use amounts you can afford to lose on mainnet. Allod trusts the machine it runs on and has no unlock password, so use full-disk encryption on hardware you own. On umbrelOS, add the repository as a community app store instead; see the Umbrel guide.
